🚀 AETHERTEST: Test Your API Like a Real Infrastructure Team

💡 THE PROBLEM:
Founders launch APIs unsure if:
• Auth will hold under real load?
• Rate limits actually stop abusers?
• QA will find missed edge cases?

⚡ THE SOLUTION:
Deploy REALISTIC AI AGENTS that behave like:
🛡️ Cautious DevOps Engineer (validates everything)
🚀 Aggressive Startup Founder (moves fast, breaks things)
🔧 SRE / Platform Engineer (monitors health & performance)
🔍 QA Engineer (tests edge cases & error conditions)

🔧 HOW IT WORKS (SIMPLE):
1. POINT: aethertest test --url https://your-api.com
2. WATCH: AI agents authenticate, test endpoints, handle errors
3. GET: Clear success report with actionable insights

⚙️ KEY FEATURES:
• Zero-configuration SQLite DB (auto-created)
• Built-in mock API for instant testing
• External API testing support
• Realistic agent behaviors & workflows
• Intelligent error handling & retries
• Per-persona success breakdown
• Failure mode analysis
